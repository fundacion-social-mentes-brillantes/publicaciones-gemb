# Publicaciones GEMB

Imágenes de las publicaciones programadas de Instagram y Facebook de Gimnasio Emocional Mentes Brillantes.

Instagram solo publica imágenes que estén en una dirección pública (no acepta enlaces de Google Drive).
Por eso cada imagen aprobada se sube a la carpeta `img/` de este repositorio, y su enlace
`https://raw.githubusercontent.com/fundacion-social-mentes-brillantes/publicaciones-gemb/main/img/<archivo>.jpg`
se pega en la columna «Imagen» del calendario de Google Sheets. Make la publica a la hora indicada.

- Formato: JPG, máximo 8 MB, de 320 a 1440 px de ancho, proporción entre 4:5 (vertical) y 1,91:1 (horizontal).
- Nombre: `AAAA-MM-DD-tema.jpg` (sin tildes ni espacios).
